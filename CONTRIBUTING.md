# Contributing to the Playbook

1. Keep explanations decision-focused and practical.
2. Mark assumptions and illustrative numbers clearly.
3. Prefer vendor-neutral guidance unless a provider-specific example is useful.
4. Include trade-offs, failure cases, security and operational considerations.
5. Add or update an ADR when a recommendation changes materially.
6. Verify current vendor pricing, quotas and product behavior before publishing them.
7. Do not include secrets, real customer data or private company architecture.
8. Use Mermaid or editable text diagrams when practical.
