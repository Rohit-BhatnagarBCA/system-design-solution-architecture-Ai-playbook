# Reference Architectures

These examples are starting points, not universal blueprints.

- `nodejs-ai-monolith/` — one deployable Node.js app with internal AI boundaries.
- `nodejs-microservices/` — multiple services with explicit ownership and contracts.
- `nodejs-rag-platform/` — document ingestion and retrieval-augmented generation.

For each real project, write down requirements, assumptions, trust boundaries, failure behavior, cost drivers and validation plan before adopting a reference design.
